ملاحظات حول استخدام CETEICean لعرض TEI في HTML

يقوم هذا الموقع على وثيقة XML واحدة بمعيار TEI، متاحة في مستودع ProjectJaraid على GitHub. تحتوي هذه الوثيقة على النص التمهيدي والبيانات في هيئة جدول معاً. تعرض صفحات HTML لهذا الموقع وثيقة TEI عبر CETEICean، مع بعض الاستثناءات (مثل هذا النص، وبالطبع صفحة الفهارس التي تعمل بتحويلات XSLT للبيانات الأصلية). وCETEICean هو شيفرة برمجية مكتوبة خصيصاً لتحويل وثيقة TEI XML إلى صيغة شبه-HTML بشكل ديناميكي. فيما يلي بعض الملاحظات الأساسية حول التنسيق وإدارة البيانات عبر CSS وJS للمبتدئين، وفق نسخة CETEICean المستخدمة هنا (تنبيه: ليست أحدث نسخة!).

  1. تُخفى الأجزاء غير الضرورية من وثيقة TEI في كل صفحة HTML عبر معرّفها (id) في CSS. الصيغة Tei-div#ID تعمل تماماً. وبهذه الطريقة أمكننا "توزيع" أجزاء وثيقة TEI XML الواحدة على عدة صفحات.
  2. في CSS، تعمل تعليمات التنسيق الأساسية بإضافة اللاحقة tei- إلى العناصر div. والنسخة المستخدمة من CETEICean تحوّل جدول TEI XML إلى جدول شبه-HTML. لذا لا حاجة في هذه الحالة لاستخدام tei-row لتنسيق الجدول في CSS، بل يعمل tr ببساطة كأن الجدول HTML ثابت.
  3. نعيد تنظيم بيانات جدول TEI XML زمنياً عبر دالة JS. ولكي تعمل هذه الدالة تلقائياً، لا يكفي ربط JS كسكربت في رأس صفحة HTML، بل يجب أيضاً إدراج شيفرة JS نفسها بجانب شيفرة CETEICean JS في الرأس، بعد تلك الشيفرة مباشرة. يمكن مراجعة الشيفرة في صفحة الفهرس الزمني عبر خاصية "فحص الصفحة" (inspect).
  4. لتنسيق جدول TEI XML تحديداً في هذه النسخة من CETEICean، لا حاجة لاستخدام لواحق tei- لخلايا الجدول وصفوفه. عناصر HTML المعتادة th وtd وtr تعمل تماماً.
  5. تنسيق CSS للعنصر داخل عنصر آخر يتطلب صيغة tei-div وtei-اسم العنصر.
  6. هناك طريقتان لعرض بيانات TEI XML على HTML:
    • في كثير من صفحات هذا الموقع، لا يستقبل CETEICean بيانات XML مباشرة من ملف TEI XML في مستودع بجانب ملف index HTML، بل تُربط عبر موقعها في GitHub كشيفرة "منشورة" (حيلة جيدة لمركزة التحديثات وأتمتتها).
    • في الصفحتين اللتين تعرضان البيانات الأساسية بالحروف اللاتينية وبالعربية، اضطررنا إلى إنشاء صفحات HTML مسبقاً، إذ كانت البيانات المرتبطة ستستغرق وقتاً طويلاً للتحميل. وفي هذه الحالة، اقترح هيو كايليس استخدام GitHub Action لإنشاء صفحات HTML تلقائياً. وبشكل عام، يعني هذا أن أي تغيير في الملف الرئيسي يُفعّل GitHub Action الذي يُنشئ، عبر شيفرة XSLT تتضمن عناصر من CETEICean، صفحتي HTML تحتويان بيانات XML مكتوبة فيهما مسبقاً.
  7. أنشأنا ملف سلطة مرجعية (authority file) بمعيار TEI XML يضم قوائم بأسماء الأشخاص والمؤسسات والأماكن بصيغ نسخ متعددة مع الإحداثيات الجغرافية. أنشأ تيل غراليرت هذا الملف باستخدام XSLT حوّل البيانات المكتوبة بالحروف اللاتينية في الملف الرئيسي إلى الخط العربي.
  8. نستخدم GitHub Action آخر، يتضمن أيضاً شيفرة XSLT، لتغذية الملف الرئيسي بالبيانات العربية المسترجعة من ملف السلطة المرجعية.

هذه الصفحة ترجمة أولية أعدّها مساعد آلي وستُراجع وتُصحَّح قريباً.
